# Seagrass OpenCode Template

This directory contains the OpenCode project template for Seagrass.

Activate it from the repository root:

```sh
ln -sfn editors/opencode/opencode.json opencode.json
```

The template points OpenCode at `AGENTS.md`, `docs/agents.md`, and
`skills/README.md` so it sees repository rules, structured CLI/LSP payloads, and
the optional Seagrass skill catalog.
